**The bridge theorem as stated** (`Tdf.Bridge.release_bridge.stmt`):

```lean
∀ (p : Spec.Policy) (s : IdSpec.Snapshot) (req : Spec.Request),
  compile p = some s → bridgeHyp p req = true →
  IdSpec.release s (intake p req) = Spec.release p req
```

`bridgeHyp` is the conjunction of four hypotheses:
- **H1 `objectFixed`:** lowercasing a parsed object label's name and value a second time changes nothing.
- **H2 `subjectFolds`:** every held claim value folds once.
- **H3 `objectSlash`:** lowercasing creates no `/` in an object string.
- **H4 `triggersOk`:** every `read` trigger's value is a label, is fixed, and is slash-stable.

Also stated: `entitled_bridge` (needs only H1 and H2), `listed_bridge`, and `hyp_of_ascii` (ASCII input satisfies H1–H4, which ties to O4).
