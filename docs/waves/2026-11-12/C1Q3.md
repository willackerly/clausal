## What a reviewer should distrust

- **Sign-off strength.** A separation's sign-off is whatever `clausal review` records, so an agent can still run that command, as for every other entry. What changed is that the inputs are compiled and must separate, the record is digest-bound, and an unsigned one fails the check.
- **Separation scope.** A separation shows one sentence per piece. It does not show that no sentence is read both ways.
- **Skeleton match is loose.** "Written with the shared skeleton" is a regex search of the skeleton's literal words inside the Rule line, not a parse-tree check.
- **c42 is caught three ways.** The noun scan (`wallet`), the import check and the alone build all fire; the control's regexes require the last two.
- **`recorded()` rewrites the expected file too.** It rewrites the lock and the expected-violations file in the scratch copy, so a control wrapped in it would not notice a lint regression its own patch caused.
