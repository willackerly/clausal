## What a reviewer should distrust

- **The refusal is decided in Python by a table.** `REASONS` in `narrowing.py` and the `narrowing:` facts in the book make the decision; the kernel checks the declared facts and the 12 control refusals on every run. A refusal of an arbitrary new sentence is not itself certified at compile time.
- **"Not provable" means the fixed tactic failed.** A true fact that `narrow_side` cannot prove is neither declared nor flagged, and a vacuous rule that depends on it would pass. The backstop on fixture rules has the same limit.
- **The certificates use the standard three axioms** (`propext`, `Classical.choice`, `Quot.sound`) because their statements mention the Aeneas model operations. The library theorems themselves use none, except `neverChanges_of_silent`, which uses `propext`.
- **Refusal is per claim.** A line with one vacuous clause among sound ones is refused whole, which is stricter than the task's wording.
- **`rd.used` now includes `calls.*` ids**, so "n of m pieces" counts in reports went up; `--strict` now also requires those entries to be signed.
- **The echo-trial mutator would silently stop working** with the new echo, so I added `c.calls = "accepted"` to `mutate.py`. The stored `items.json` still has the old wording and I did not regenerate or rerun that bank.

## What a reviewer should distrust

- **`badstatement` rests on `Expr.hasSorry` of the type.** It catches statements Lean recovers from with `sorry`. A statement that elaborates to something well-typed but unintended is still invisible.

- **The new sequence texts are my wording.** They say acceptance is judged on the last call and earlier answers are not looked at, which I read off `Op.andThen` (`accepted := second.accepted`). They are not signed off.
- **The `NARROWED-TWICE` refusal only fires when no other full composition of the line exists.** If another reading without the double words compiles, that reading is taken.
- **Two self-test controls (E, F) fail by raising, not by a clean FAIL line.** When the subject-plus-claim refusal is removed, the emitter guard raises before the check prints.
